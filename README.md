
# Azure End-to-End Data Engineering Project

## Project Overview

This project demonstrates how to build a modern end-to-end data engineering pipeline on Microsoft Azure using industry-standard tools and best practices.

The pipeline ingests raw retail sales data, stores it in Azure Data Lake Storage, transforms it using Azure Databricks (PySpark), loads the curated data into Azure SQL Database, and visualizes business insights using Power BI.
